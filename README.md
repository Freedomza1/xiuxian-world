## ✨ 它是什么

打开 `index.html`，你是一个 16 岁的凡人少年，从「炼体一重 · 练气一层」开始：

- ☯️ **修炼**：炼体 + 炼气双体系，突破要渡天地之劫
- ⚗️ **炼丹**：收集丹方 → 备齐药材 → 丹炉前控火候 → 成丹（品质浮动）
- 🔨 **炼器**：采集矿石灵材 → 锻造法器（品质随机）
- 🐉 **灵兽**：驯服野生灵兽 → 培养 → 出战辅助
- 🏯 **宗门**：加入门派、拜师、宗门故事、山门禁地
- 🗺️ **秘境**：悟道景观、试炼塔、遗迹探索、第二纪元「冰阁传承」
- ⚔️ **江湖**：剧情人物、任务线、名声与业力
- 💬 **AI 对话**：NPC 会用 DeepSeek 与你实时对话、顿悟、叙事

## 🤖 AI 共创 —— 这台游戏怎么诞生的

这不是一个"手写脚本"，而是一个 **人类 + AI 协同创作**的完整案例：

- **叙事引擎**：`narrative.js` 调用 DeepSeek，用散文式语言渲染每一次行动（"像读一卷闲书，不赶不抢"）
- **NPC 灵魂**：NPC 不再是死板文本，AI 让每个角色有了"活着"的对话
- **顿悟与自创功法**：`enlightenment.js` 由 AI 生成顿悟剧情与神级功法
- **冰仙子**：`ice_fairy.js` 里的攻略对象，由 AI 驱动的专属互动
- **我在其中做了什么**：定义玩法规则、系统咬合、UI 与数值、把 AI 的"灵感"收敛成可玩的闭环

> 我把 AI 当作"同行的小说家与编剧"，我负责世界观的骨架与玩法，AI 负责把每一刻写活。

## 🚀 快速运行

**方式一（推荐，无需任何依赖）**

直接用浏览器打开 `index.html` 即可运行（游戏核心为纯静态，无后端依赖）。

**方式二（本地服务器）**

```bash
npm start
# 或
python3 -m http.server 8080
# 打开 http://localhost:8080
```

**配置你自己的 AI Key（可选）**

想让 NPC 拥有 AI 灵魂，把 `config.example.js` 复制为 `config.js`，填入你的 DeepSeek API Key：

```bash
cp config.example.js config.js
# 编辑 config.js，填入 DEEPSEEK_API_KEY / ICE_FAIRY_API_KEY
```

> 获取 Key：<https://platform.deepseek.com/>。若未配置，游戏主体玩法仍可完整游玩，仅 AI 对话/叙事功能不可用。

## 🎯 设计哲学

- **文字即世界**：不靠特效，靠"读得慢、读得细"的散文笔触构建沉浸感
- **每个系统都有"身体感"**：突破不是弹卡片，而是一场天地与身体的对话
- **世界会记住你**：名声、业力、寿命、人物传记——你点的不是属性表，是自己的一生
